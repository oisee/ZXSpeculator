## Fork Purpose
> **Agent note:** This fork adds DZRP (DeZog Remote Protocol) for external debugging support. The goal is to enable .minz language development with full debugging capabilities.

This is a fork of ZX Speculator that adds:
- **DZRP Server** (`Speculator.Core/Dzrp/`) - TCP server on port 11000 for VS Code debugging
- **External Debug Control** - Pause, continue, breakpoints, register/memory access
- **.minz Language Support** - Runtime environment for debugging .minz programs

### Key DZRP Files
- `DzrpServer.cs` - TCP listener, manages connections
- `DzrpSession.cs` - Protocol handler per client
- `DzrpDebugBridge.cs` - Bridges protocol to CPU/memory/registers
- `DzrpBreakpoint.cs` - Breakpoint management with unique IDs
